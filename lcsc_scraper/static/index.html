测试建议：条数填 2 快速验证；正式采集填 1500。并发不宜过大，以免触发网站限流。
图片过滤：立创部分商品的「图片」是品牌证书图（同一品牌下所有商品共用一张，缩略图完全相同）、云汉可能是默认占位图，这些不是商品实拍图，默认跳过（约占实测数据的 11%）。选「只保留有商品实拍图」会连同无图商品一起跳过（无图约占 44%）。
数据手册过滤：跳过没有数据手册 PDF 链接的商品，仅对立创生效（华秋 / 云汉 没有该字段，勾了也不会让它们被清空）。
数据库去重设置（可选）：跳过 nshop_tp8_v2.sp_goods 中已存在的商品
留空则读取 lcsc_scraper/db_config.json（或环境变量 DB_HOST 等）；两者都没有时自动跳过该过滤，不影响采集。
采集到的「商品编号」命中商品编号字段，或「型号」命中型号字段（忽略大小写与空格）即视为已存在、直接跳过。（在 db_config.json 里把字段名写成空串 "" 可关闭对应规则。）
华秋登录 Cookie（华秋采集必填）：列表接口现在要求登录态
获取方式：在已登录华秋的浏览器里按 F12 → Network → 刷新页面 → 点任一 hqchip.com 请求 → Request Headers 里复制整条 Cookie 值，粘贴到上面。留空则读取 lcsc_scraper/hqchip_config.json 的 cookie 字段（或环境变量 HQCHIP_COOKIE）。 该 Cookie 等同于登录凭证，请勿提交到版本库。
